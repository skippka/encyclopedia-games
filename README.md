# Енциклопедія відеоігор

Це мій практичний проект на C# WinForms. Програма зроблена як невелика енциклопедія ігор: можна дивитися список ігор, шукати їх, фільтрувати по категоріях, додавати нові записи, редагувати старі і відкривати галерею з обкладинками.

Дані зберігаються у SQLite базі `games.db`. Якщо бази ще немає, програма сама створює її при першому запуску і додає 40 прикладів ігор.

## Що є в програмі

- таблиця з іграми через `DataGridView`;
- пошук по назві та жанру;
- фільтр по категоріях через SQL-запит;
- підсвічування старих і нових ігор;
- додавання, редагування і видалення записів;
- кнопка оновлення таблиці;
- вибір файлів через `OpenFileDialog`;
- копіювання обкладинок, відео і HTML у папку `Assets`;
- галерея обкладинок з мініатюрами;
- слайд-шоу через `Timer`;
- детальний перегляд з HTML-описом через `WebView2`;
- відео/аудіо через `AxWindowsMediaPlayer`, якщо файл доданий.

У проекті вже є готова база `games.db` і кілька коротких відео у папці `Assets/media` для перевірки плеєра.

## Як запустити

1. Відкрити файл `GameEncyclopedia.csproj` у Visual Studio.
2. Дочекатися, поки Visual Studio відновить NuGet-пакети.
3. Запустити проект кнопкою Start.
4. При першому запуску створиться база `games.db`.

Потрібно, щоб у Visual Studio були встановлені компоненти для Windows Forms і .NET 8.

## Структура

- `MainForm.cs` - головне вікно з таблицею.
- `EditForm.cs` - форма додавання і редагування.
- `GalleryForm.cs` - галерея обкладинок.
- `MediaForm.cs` - перегляд HTML та відео.
- `Database.cs` - робота з SQLite.
- `Assets` - картинки та HTML-файли.


## Примітка

У базі зберігаються не самі файли, а тільки шляхи до них. Самі файли лежать у папці `Assets`.
